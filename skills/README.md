# Skills del despacho

Fuente de verdad de las skills `redactar2` (v1.3) y `redaccion-consideraciones` (v2.1).
Los archivos `.zip` son los paquetes listos para subir a claude.ai
(Configuración → Capacidades → Skills → Subir skill), reemplazando la versión anterior.

Ambas usan el conector «Verificador jurisprudencial» (servidor en `../mcp/`) cuando está
activado en la sesión. Estado de portales y protocolo de uso: `redactar2/references/mcp-y-herramientas.md`
y `redaccion-consideraciones/references/fuentes-oficiales.md`.
